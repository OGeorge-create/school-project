# A-Z Waterproofing and Construction Website

A responsive, lightweight, multi-page website for **A-Z Waterproofing and Construction** (Kumasi, Ghana).

## Architecture: Pure Standalone HTML5 / CSS3 / JavaScript
- **No Node.js or npm required**
- **No Vite or build tools required**
- **No dependencies to install**

Everything runs directly in any browser out of the box.

---

## Directory Structure

```text
furnish-v1.0.0/
├── index.html            # Home page (Hero slider, featured products, rainproofing banner)
├── about.html            # About Us (Company story, mission, core values, team)
├── products.html         # Catalog (Retail/Wholesale coatings, D.P.C, primers, sealants)
├── testimonials.html     # Client reviews & testimonials from Kumasi and across Ghana
├── contact.html          # Contact info, Kumasi showroom address, quote request form, map
├── assets/
│   ├── css/
│   │   └── style.css     # Complete compiled styles (Bootstrap 5.3 + custom theme tokens)
│   ├── js/
│   │   └── main.js       # Standalone vanilla JavaScript (Swiper carousel initialization)
│   ├── images/           # Product photos, hero slider assets, and avatar visuals
│   ├── bootstrap-icons.woff
│   └── bootstrap-icons.woff2
├── PROJECT_DOCUMENTATION.md
└── README.md
```
